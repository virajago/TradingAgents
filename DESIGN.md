# AI Analyst Weekly — Design System

Generated by /plan-design-review on 2026-05-09.
Supersedes: nothing (first design system for this project).

This is the source of truth for all visual design decisions. Every frontend
developer reads this before writing a line of CSS or selecting a component.

## Product Context

**Target user:** 40-55, professional or executive, $100k-$500k portfolio.
**Trust signal:** Must feel like Bloomberg Terminal meets Financial Times, not a
startup SaaS newsletter. This person trusts Morningstar and WSJ Premium.

## Visual Direction: Clean Editorial

White background, dark editorial typography, deep blue accent, forest green/crimson
for financial signals. NOT: purple gradients, icon circles, 3-column card grids,
emoji as design elements, any startup-SaaS aesthetic.

## Color Tokens

All colors defined as CSS variables. Never hardcode hex values — always use tokens.

```css
:root {
  --color-background:     #fafafa;   /* off-white page background */
  --color-surface:        #ffffff;   /* card and panel backgrounds */
  --color-surface-2:      #f4f4f4;   /* subtle dividers, alt rows */
  --color-border:         #e0e0e0;   /* card borders, input borders */
  --color-text-primary:   #1a1a1a;   /* headlines and body text */
  --color-text-secondary: #4a4a4a;   /* captions, secondary labels */
  --color-text-tertiary:  #8a8a8a;   /* timestamps, disclaimers */
  --color-accent:         #1e4d8c;   /* links, primary buttons, focus rings */
  --color-accent-hover:   #163a6b;   /* darker on hover/active */

  /* Verdict system — deliberate, not traffic-light */
  --color-bullish:        #1a6b3c;   /* forest green for positive conviction */
  --color-bullish-bg:     #e8f5ee;   /* light green badge backgrounds */
  --color-bearish:        #8b1a1a;   /* deep crimson for negative conviction */
  --color-bearish-bg:     #fbeaea;   /* light red badge backgrounds */
  --color-neutral:        #4a4a4a;   /* same as text-secondary — neutral is non-event */
  --color-neutral-bg:     #f0f0f0;   /* light gray badge backgrounds */
}
```

## Typography

**Never use:** Inter, Roboto, Arial, system-ui, -apple-system as the primary
display or body font. These signal "I gave up on typography."

## Verdict Vocabulary

Three-tier system (not 5-tier Buy/Sell to reduce regulatory risk):

| Verdict | Color token | Conviction display |
|---|---|---|
| BULLISH | `--color-bullish` on `--color-bullish-bg` | "BULLISH — High conviction (87%)" |
| NEUTRAL | `--color-neutral` on `--color-neutral-bg` | "NEUTRAL — Mixed signals" |
| BEARISH | `--color-bearish` on `--color-bearish-bg` | "BEARISH — Moderate conviction (71%)" |

**Conviction modifier:** "High" (>80% agent agreement), "Moderate" (60-80%),
"Low" (<60%). Always display the agreement percentage.

## Spacing Scale

Use 4px base unit. Multiples: 4, 8, 12, 16, 24, 32, 48, 64, 96.
No arbitrary spacing values.

## Border Radius

Cards: 4px. Inputs: 4px. Buttons: 6px. Verdict badges: 3px.
**Not:** large uniform border-radius (bubbly aesthetic). Keep it tight and professional.

## Navigation

- **Desktop:** Left sidebar, 240px wide, collapsible to 48px. Items: Analyze, Watchlist, Portfolio, Journal, Settings.
- **Mobile:** Bottom tab bar, 5 items: Analyze, Watchlist, Portfolio, Journal, Settings. Track Record is a sub-page of Journal.
- **No hamburger menus.**

## Accessibility Requirements

- **Touch targets:** 44px minimum height on all interactive elements.
- **Color contrast:** 4.5:1 for body text, 3:1 for large text (18px+ bold or 24px+). Verdict badges must meet 4.5:1.
- **Keyboard navigation:** Tab order follows visual reading order. Focus ring: 2px solid `--color-accent`, 2px offset.
- **Form labels:** Always visible, always above the input. NEVER placeholder-as-label.
- **Screen readers:** Verdict badges need `aria-label`. Example: `aria-label="BULLISH — High conviction, 87% of analysts agree"`.
- **Email:** Use semantic HTML. All information must be readable in text-only clients. Verdict colors supplement, never replace, text labels.

## AI Slop Blacklist — Never Ship These

1. Purple/violet/indigo gradients or color schemes
2. 3-column feature grid: icon-in-colored-circle + bold title + 2-line description
3. Icons in colored circles as section decoration
4. Centered everything (`text-align: center` on headings, cards, descriptions)
5. Uniform large border-radius on all elements
6. Decorative blobs, wavy SVG dividers, floating shapes
7. Emoji as design elements (one exception: the flag emoji ⚑ in alert subject lines is functional)
8. Colored left-border on cards
9. Generic hero copy ("Welcome to X", "Unlock the power of...")
10. Cookie-cutter SaaS rhythm (hero → 3 features → testimonials → pricing → CTA all same height)

## Email Templates

**Format:** HTML (MJML or React Email). NOT plain-text.
**Test on:** Gmail (web), Gmail (iOS), Outlook, Apple Mail before first send.
**Verdict badges in email:** Inline HTML `<span>` with background-color. Falls back to text in text-only clients.

### Weekly Digest Structure
1. Subject: "Your Sunday Report: NVDA Bullish, AAPL Neutral, +3 more"
2. Preview text: lead with most contrarian call
3. Header: portfolio total P&L, sector exposure summary
4. Stock cards (ranked by conviction strength, descending)
5. Footer: legal disclaimer, unsubscribe, "Run on-demand" CTA

### Red Flag Alert Structure
1. Subject: "⚑ NVDA down 8% — what our analysis shows right now"
2. One paragraph: fast single-agent summary (30-60 second generation)
3. CTA: "Run full 8-analyst analysis →" (links to on-demand form, pre-filled)

## Landing Page

**Classifier:** MARKETING. Brand-forward, conversion-focused.

**Hero (first viewport, one composition):**
- Left column: Brand name (top-left). Headline. Subhead. CTA button.
- Right column: Truncated live sample analysis card (real NVDA report, updated weekly)
- Headline: "The research your broker charges $500/month for. We charge $39."
- Subhead: "Every Sunday, 8 AI analysts debate every stock in your watchlist."
- CTA: "Start your first week →" (single action, no friction)
- NO: 3-column features, centered layout, illustration, stock photos, gradients

**Section order:**
1. Hero (above fold, conversion-focused)
2. How it works (3 steps, prose not cards)
3. Sample analysis (full rendered example, gated at 50%)
4. Pricing + FAQ (one price, seven FAQ items)
